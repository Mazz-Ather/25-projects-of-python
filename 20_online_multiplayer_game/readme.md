To run the Tic-Tac-Toe multiplayer game, you need to follow these steps:

1. First, run the server in one terminal:
```bash
python e:\Python\04_assignment_and_projects\25_projects\20_online_multiplayer_game\server.py
 ```
```

You should see: "Server started. Waiting for players..."

2. Then, run the client in another terminal:
```bash
python e:\Python\04_assignment_and_projects\25_projects\20_online_multiplayer_game\client.py
 ```
```

3. For a two-player game, open a third terminal and run another instance of the client:
```bash
`python e:\Python\04_assignment_and_projects\25_projects\20_online_multiplayer_game\client.py
` ```
```
